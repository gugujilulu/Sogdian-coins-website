# T22 范围建设小批次

基线与对象见[完整登记表](POLITY-RANGE-REGISTER.md)。本轮只完成T22-1；T22-2及以后**尚未启动**。T21视觉已经用户验收并集成；后续沿用，不重复美术选型。

## 基础任务

- **T22-1（本轮完成，待集成）**：78项清单、记录ID去重计数、来源线索、全覆盖批次和路线同步。仅文档。
- **T22-2（未启动；依赖T22-1集成）**：定义范围自身年代、未知起止/开区间、全部时期/指定年份/年代未知、多版本选择的显示规则；本部/附属/影响及裁切语义分开；不得继承钱币年代，不复核西辽几何含义。交付规则文档、现有适配所需最小逻辑及针对性测试，不制作新范围。
- **T22-3（未启动；依赖T22-2）**：统一可复用接入流程：稳定对象/范围/版本ID、来源及原件登记、配准/描绘记录、填色闭合与可见边界分离、未知/裁切状态、既有钱币关联、验证和截图模板。复用T21实现，不重构全库、不制作新政权范围。

## 执行次序与负荷

T22-4至T22-81是**78个实际范围首批任务**，每卡仅一个原有建设身份；不将资料未准备的多个对象塞成一批。地域与同名政权不合并，前批来源和配准成果可复用，空间含义需分别确认。按已有Bregel线索→七河→粟特地方体系→吐火罗/巴克特里亚→新疆与后期体系→争议标签安排。西辽复核置后并保持明确暂停。

这些卡不是“所有时代一口气完成”：每批最多一个有来源的明确时期/地域资料版本、一次局部配准描绘，不包含大规模拼图。尚无具体时期时，锁定时期和寻找范围资料本身计入工作量，禁止凭名称预定年代。每卡下列“续批槽”专门承接该对象剩余时期/附属或未覆盖部分，不与首批混做。槽是待拆执行任务，**不能直接启动为无限研究任务**：首批发现具体余项时，协调窗口按一时期/一部分在本序列末尾追加连续T22编号、登记来源缺口和验收，替换槽的待拆状态；未拆/未完成不得标对象完成，也不得跳到T23。没有已知分期则如实写待定，不虚构时段。

T23排在上述完整范围建设序列及其续批之后；单独用户明确暂缓的西辽复核保留为可见暂停项，不偷偷视为完成。其他卡资料不足可以保存partial并执行另一可开展卡，但必须把缺口留在对应续批槽，不能以框架完成或零匹配删掉建设对象。后续调整须显式更新此表和STATUS。

## 每批共用完成标准（以下每卡均引用）

1. 保存有出处的范围数据、原始来源入口/原件留存位置、页码图号、描绘/配准方法，明确该版本自身时期及空间含义。
2. 区分本部、附属、影响与地域背景；裁切边不冒充政治边界；未知部分、未绘部分和资料精度明示。
3. 只使用已有可靠钱币关系；不根据范围包含点推断钱币发行/铸地/流通，不改原Atlas、manifest、来源和ID。零匹配对象照常保留。
4. 交付代表截图、必要几何/关联/时间检查、提交、推送并核实远端SHA。涉及运行时代码才做相应类型检查/构建，不每批重跑全库研究。
5. 无关键证据则保留已取得成果、具体缺口及下一动作，状态partial；不得为了交付随意闭合。首批局部成果不等于对象全时期完成。
